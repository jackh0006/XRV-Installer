## Please read

- A donation is irreversible.
- A donation is not an investment, a purchase, or a support contract.
- Never send a recovery phrase or private key to anyone. No maintainer will
  ever ask for one.
- Donations are never requested inside a transaction confirmation screen.
- If an address here ever disagrees with the source repository, the source
  repository is authoritative.

## Non-financial support

- Star the repository and share it with someone who needs it.
- Open a focused bug report or feature request.
- Improve the documentation or tests.
- Report security issues privately through
  [SECURITY.md](SECURITY.md).
